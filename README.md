# Digital Electronic

Aplikasi kasir (POS) profesional untuk toko elektronik — PHP + MySQL.

## Install (XAMPP / Laragon)

1. Copy folder `DigitalElectronic` ke `htdocs`
2. Import `database.sql` di phpMyAdmin
3. Jalankan juga `upgrade.sql` (jika DB sudah ada sebelumnya)
4. Buka: `http://localhost/DigitalElectronic/login.php`

## Fitur

- Kasir multi-item + keranjang + pilih qty
- Diskon, kembalian, multi metode bayar
- Cetak struk
- Dashboard grafik + produk terlaris
- **Portofolio dashboard**
- Pengaturan toko
- Pengeluaran & karyawan
- Navigasi mobile (bottom nav + FAB keranjang)
- Responsif PC / laptop / tablet / HP
